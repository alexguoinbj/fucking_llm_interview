# 12.7 文生图与视频生成模型 — 题目与答案
> [⬅ 返回目录](../README_ZH.md) · 第 12 章：多模态大模型 · 共 16 题

**1. 什么是文生图模型（Text-to-Image）？举例说明常见的技术路线**

<details>
<summary>💡 查看答案</summary>

文生图模型指根据用户输入的一段自然语言文本描述，自动生成与该描述语义相符的图像内容的模型，是当前生成式 AI 领域最受关注的应用方向之一（如 Stable Diffusion、DALL-E、Midjourney 等知名产品均属于这一类别）。其核心挑战在于如何将文本这种离散的符号化描述，准确地转换为像素空间中连续、丰富的视觉内容，同时保证生成图像既符合文本描述的语义要求，又具有良好的视觉质量和美感。

当前主流的技术路线主要有两条：

- **基于扩散模型（Diffusion Model）的路线**：以文本描述作为条件，通过迭代式的"去噪"过程，从一个随机噪声图逐步生成最终的清晰图像，是目前生成质量最高、应用最广泛的技术路线（如 Stable Diffusion、DALL-E 3、Imagen 均采用此路线）；
- **基于自回归（Autoregressive）的路线**：先将图像通过 VQ-VAE 等方法转换为离散的视觉 Token 序列，再用类似语言模型的自回归 Transformer，以文本为条件逐个预测生成这些视觉 Token（最早的 DALL-E 即采用此思路，近期的 VAR、LlamaGen 等工作在此基础上做了进一步改进）。
目前扩散模型路线在生成质量、细节丰富度上普遍占据优势，是当前文生图领域的主流选择；自回归路线的优势在于更容易与语言模型的自回归生成范式统一，是"图像理解+生成一体化"模型探索的重要方向。

</details>

**2. 扩散模型核心思想及其适合生成的原因**

<details>
<summary>💡 查看答案</summary>

**核心思想**：通过"前向加噪"将数据逐步加噪为纯噪声，再训练模型学习"反向去噪"过程，从噪声逐步恢复数据；生成时从随机噪声出发，通过学习到的去噪过程逐步生成目标图像。

**适合生成的原因**：
- 天然适合建模连续空间中的数据分布（如像素值）。
- 迭代去噪过程允许模型在每一步做"小幅修正"，逐步提升生成质量。
- 训练目标简单（预测噪声），不需要对抗训练（GAN 的判别器-生成器博弈）。
- 通过 Classifier-Free Guidance 可以灵活控制生成结果与条件的匹配程度。

</details>

**3. 什么是 Classifier-Free Guidance（CFG）？它在文生图中的作用是什么？**

<details>
<summary>💡 查看答案</summary>

在早期的条件扩散模型研究中，为了让生成结果更贴近给定的条件（如文本描述），一种做法是额外训练一个独立的分类器，在采样过程中利用该分类器的梯度信息引导生成方向（Classifier Guidance），但这种方式需要额外训练和维护一个分类器，实现复杂且不够灵活。

Classifier-Free Guidance（CFG，无分类器引导）提供了一种更简洁的替代方案：在**同一个**扩散模型的训练过程中，让模型同时学习"有文本条件"和"无文本条件（即将文本输入替换为空字符串或特殊的空条件标记）"两种情况下的生成能力（训练时按一定概率随机丢弃文本条件）。在实际生成（采样）阶段，模型分别计算"给定文本条件"时的噪声预测结果 $\epsilon_{cond}$ 和"不给定文本条件"时的噪声预测结果 $\epsilon_{uncond}$，然后按照如下公式将两者的差异按一个权重系数 $w$（即 Guidance Scale，引导强度）放大：$\epsilon_{final} = \epsilon_{uncond} + w \times (\epsilon_{cond} - \epsilon_{uncond})$。这个差值 $(\epsilon_{cond} - \epsilon_{uncond})$ 本质上代表了"文本条件所带来的额外方向信息"，通过放大这个方向，可以让最终生成结果更强烈地朝着符合文本描述的方向靠拢。

Guidance Scale（$w$）的取值直接影响生成效果：$w$ 越大，生成结果与文本描述的相关性和贴合度越强，但过大的 $w$ 也容易导致图像出现过度饱和、对比度过高、细节失真等质量下降的副作用；$w$ 过小则生成结果可能与文本描述的匹配度不足。实践中通常需要根据具体模型和任务，将 $w$ 调节到一个合适的中间数值（常见取值范围在 5-15 左右），以在"文本贴合度"和"图像质量"之间取得较好的平衡。

</details>

**4. 什么是 Diffusion Transformer（DiT）？相比传统基于 U-Net 的扩散模型有什么优势？**

<details>
<summary>💡 查看答案</summary>

早期的扩散模型（如原始的 DDPM、Stable Diffusion 1.x/2.x）普遍采用 U-Net（一种带有编码器-解码器结构和跳跃连接的卷积神经网络）作为学习"去噪"这一核心任务的骨干网络。DiT（Diffusion Transformer）提出了一种不同的思路：将（潜在空间中的）图像同样像 ViT 处理图像那样，切分为一系列 Patch，把这些 Patch Token 输入标准的 Transformer 架构进行处理，用 Transformer 完全替代 U-Net 承担去噪网络的角色。

相比传统的 U-Net 架构，DiT 的优势主要体现在：

- **更好、更明确的可扩展性（Scaling 特性）**：Transformer 架构在语言模型领域已经被大量实践证明具有非常良好、可预测的 Scaling Law——即模型规模、数据量、算力的增加，能够带来相对稳定和可预测的性能提升。相比之下，U-Net 这类卷积架构的 Scaling 规律不如 Transformer 清晰和稳定。DiT 的提出证明了扩散模型的去噪骨干同样可以享受到这种"越大越强"的 Scaling 红利，为持续通过扩大模型规模提升生成质量提供了更可靠的架构基础；
- **更自然地融合条件控制信息**：Transformer 天然基于 Attention 机制，可以非常灵活、统一地将文本条件（文本 Token 的嵌入）、时间步信息等各类条件信号，通过 Cross-Attention 或者将条件信息也当作额外 Token 拼接输入序列等方式，与图像 Patch Token 进行充分交互，这种融合方式相比 U-Net 中依赖特定卷积层插入条件信息的方式更加统一和灵活，也更容易扩展支持更多种类的条件控制（如同时接受文本、姿态骨架图等多种条件）。
正是基于这些优势，DiT 架构已经成为 Stable Diffusion 3、FLUX 等新一代先进文生图/文生视频模型的主流选择，逐步取代了早期基于 U-Net 的扩散模型架构。

</details>

**5. 什么是 Latent Diffusion（潜在扩散）？为什么它能大幅降低计算成本？**

<details>
<summary>💡 查看答案</summary>

早期的扩散模型直接在原始的高分辨率像素空间上进行加噪和去噪的完整迭代过程，例如生成一张 512×512 分辨率的图像，扩散过程需要在包含数十万个像素值的高维空间中反复迭代计算，计算量和显存开销都非常庞大，这使得训练和推理的成本居高不下。

Latent Diffusion（潜在扩散，Stable Diffusion 系列即基于此思路）提出了一种更高效的解决方案：**不直接在原始像素空间中做扩散**，而是先训练一个自编码器（通常是 VAE，变分自编码器），将原始图像压缩编码为一个维度**远小于**原始像素空间的**潜在表示**（Latent Representation，例如将 512×512×3 的像素图像压缩为 64×64×4 的潜在特征图，空间维度压缩了 8 倍）。随后，整个扩散模型的加噪和去噪过程，都完全在这个低维的潜在空间中进行——模型学习的是"如何在潜在空间中从噪声恢复出有意义的潜在表示"，而不是直接在像素空间中操作。生成完成后，再用 VAE 的解码器部分，将最终生成的潜在表示重新解码还原为完整的像素图像。

由于潜在空间的维度远小于原始像素空间（在上述例子中数据量减少了 $8 \times 8 = 64$ 倍），扩散模型每一步迭代所需处理的数据规模、对应的计算量和显存占用都大幅降低，使得在有限的算力资源下训练更大规模、生成更高分辨率图像的扩散模型成为可能；同时，由于 VAE 的压缩和重建过程本身经过了专门训练，能够较好地保留图像的关键视觉信息，这种"先压缩再扩散、最后解压"的策略所引入的质量损失相对可控，在实践中被证明是计算效率和生成质量之间非常成功的一种权衡方案，也是 Stable Diffusion 能够在消费级 GPU 上运行的关键技术基础。

![潜在扩散模型 (Latent Diffusion Model, LDM) 基本原理](https://img.pricenode.uk/llm_interview_questions/zhongw/chapter12/fig_latent_diffusion.png)

</details>

**6. 图像生成模型与图像理解模型的技术路线异同**

<details>
<summary>💡 查看答案</summary>

**相同点**：都依赖强大的视觉特征提取能力；都受益于大规模预训练。

**不同点**：
- **理解模型**：以判别式为主，输入图像提取语义特征，输出文本描述/分类。
- **生成模型**：以生成式为主，从噪声或文本条件出发，迭代生成像素/潜在表示。主流技术路线包括扩散模型（Stable Diffusion）和自回归模型（DALL-E）。
- **架构差异**：理解模型通常用 ViT + LLM；生成模型用 U-Net/DiT + 文本编码器。

</details>

**7. T2I、T2V、I2V 的难点**

<details>
<summary>💡 查看答案</summary>

1. **T2I（文生图）的难点**：**文本-图像语义对齐精度**——模型需要准确理解文本描述中的每一个细节要求并在图像中体现出来，尤其是当提示词包含多个物体、多重限定条件时容易出现遗漏或混淆；**细粒度属性绑定**——当描述中涉及多个物体及其各自的颜色、数量、空间位置关系时（如"左边一个红色的球，右边两个蓝色的方块"），模型容易出现属性"张冠李戴"的错误（把颜色绑定到错误的物体上）；**文本渲染**——在生成图像中准确显示指定的文字内容（如招牌上的文字、书本封面标题）历来是文生图模型的一大短板（详见下一题）。
2. **T2V（文生视频）的难点**：**时序一致性**——需要保证生成视频中同一物体在不同帧之间保持外观、形状的连贯性，不能出现前后帧物体形态突变的"闪烁"现象；**动作合理性**——生成的运动过程需要符合物理规律和常识（如人物行走的步态、物体下落的轨迹），而不是简单地在不同帧之间做随意的插值；**长视频生成的累积误差**——随着生成视频时长的增加，早期帧中的微小误差会在后续帧的生成过程中被不断放大和累积，导致视频后半段质量明显下降或内容漂移；**计算成本极高**——视频数据量远超单张图像，训练和推理所需的计算资源是文生图任务的数量级增长。
3. **I2V（图生视频）的难点**：**首帧一致性与动态引入的平衡**——既需要严格保持生成视频的第一帧与用户提供的原始输入图像完全一致，又要在此基础上合理地引入符合逻辑的运动和变化，两者需要精细平衡；**运动幅度的控制**——运动过小则视频显得呆板缺乏动感，运动过大又容易破坏原图的结构完整性和身份一致性（如人物变形失真）；**前景与背景运动的协调**——需要保证画面中多个运动主体（前景人物、背景环境元素）的运动在视觉上相互协调、符合同一物理场景的常识逻辑，而不是各自独立地做不合理的运动。

</details>

**8. 文生图模型中常见的"文本渲染"（在生成图像中正确显示文字）问题为什么特别困难？**

<details>
<summary>💡 查看答案</summary>

让文生图模型在生成的图像中准确显示出指定的文字内容（例如"生成一张写着'Happy Birthday'的蛋糕图片"），长期以来都是这类模型的一个显著短板，其困难的根本原因在于文字和普通视觉内容在信息本质上的差异：

- **文字是需要"精确复现"的离散符号，而扩散模型学习的是像素的统计分布**：普通的视觉内容（如一片树叶、一朵云）即便生成结果与真实情况存在一定的细微差异，通常也不会显得"错误"（毕竟自然界的树叶形状本身就千变万化）；但文字则完全不同——文字的每一个笔画、每一处细节结构都必须精确无误地对应到正确的字符形状上，哪怕一个笔画的缺失或多余，都会导致文字变得无法识别或含义完全错误。而扩散模型的训练目标本质上是学习自然图像整体的像素统计分布规律，并不天然具备对这种"零容错"精确符号的建模能力；
- **文本编码器提取的是语义级特征，而非字符级的精确形状信息**：文生图模型通常使用 CLIP 等文本编码器将输入的文字描述转换为条件向量，而这类编码器的训练目标是捕捉文本的**整体语义**（例如理解"生日蛋糕"这一概念），而非精确记录每个字符具体应该是什么形状、如何排布，这导致模型在生成阶段"知道应该有文字"，但缺乏关于文字具体字形的精确指导信息，容易生成"看起来像是文字、但实际上是无意义乱码笔画"的结果。
近期的一些改进方案尝试通过引入专门的字符级别文本编码器（更精细地保留每个字符的形状信息）、大幅增大模型规模、以及构造专门包含大量准确文字渲染样本的针对性训练数据，来逐步改善这一问题，但即便是当前最先进的文生图模型，在生成较长文字段落或非拉丁字符（如中文）时，出错概率依然明显高于生成普通视觉内容。

</details>

**9. 为什么扩散模型在图像生成上表现优异，但在文本生成上不是主流方案？**

<details>
<summary>💡 查看答案</summary>

这一问题的根源在于图像和文本这两种模态数据在**连续性**上的本质差异：

图像（尤其是在像素或经过 VAE 编码后的潜在表示层面）本质上是**连续**的数值信号——像素值可以在一个连续的数值范围内平滑变化，扩散模型"从纯噪声出发、逐步小幅去噪"的迭代生成过程，天然适合在这种连续空间中平滑地建模和生成数据，每一步的微小噪声去除都对应着数据分布上的合理、连续的变化。

而文本本质上是**离散**的符号序列——每一个词或子词都是词表中一个孤立的、不连续的离散符号，词与词之间不存在类似像素值那样的"连续过渡"关系（例如"猫"和"狗"这两个词在语义上可能相关，但并不存在一个介于两者"数值中间"的合理词）。将扩散模型的连续加噪-去噪框架直接套用到这种离散符号空间上并不自然，需要额外的特殊处理，例如先将离散的词映射到一个连续的嵌入空间中进行扩散（再在生成完成后映射回离散词），或者专门设计针对离散状态转移的"离散扩散过程"，这些方案在实现复杂度上都要高于连续扩散的图像生成。

此外，从工程生态的角度看，当前的自回归 Transformer 语言模型架构已经在训练效率、推理加速（尤其是 KV Cache 机制带来的巨大推理提速）、以及配套的开发工具链等方面高度成熟，相比之下，离散扩散文本生成模型在这些方面的成熟度和生态积累都还远远不及自回归范式。综合生成质量、训练/推理效率以及现有生态的兼容性等多方面因素，自回归 Transformer 目前仍是文本生成领域公认的主流范式，扩散模型在文本生成上的探索虽然是一个活跃的研究方向，但距离取代自回归范式还有相当距离。

</details>

**10. 什么是 ControlNet？如何实现对生成图像的精细控制？**

<details>
<summary>💡 查看答案</summary>

标准的文生图模型仅接受文本作为条件输入，用户很难通过文字精确控制生成图像中物体的具体姿态、构图布局或轮廓形状（例如很难用文字精确描述"人物左手抬起 45 度角"这类具体的空间细节）。ControlNet 的核心目标就是让扩散模型能够接受**额外的结构化条件输入**（如 Canny 边缘图、深度图、人体姿态骨架图、涂鸦草图、语义分割图等），从而实现对生成结果的精细化控制。

其实现方式是：将预训练扩散模型（如 Stable Diffusion）的 U-Net 编码器部分**复制一份**作为新的、可训练的"控制分支"，原始的 U-Net 主干权重保持冻结不变。控制分支接收额外的条件图像作为输入，其每一层的输出特征通过一个**零卷积层**（Zero Convolution，一种权重被初始化为全零的 1×1 卷积）注入到原始 U-Net 对应层的特征图中。零卷积的巧妙之处在于：由于其权重初始化为零，训练刚开始时，无论控制分支输出什么内容，经过零卷积后都会被"清零"，对原始 U-Net 的行为完全没有影响，这保证了训练一开始不会破坏预训练模型已经具备的强大生成能力；随着训练的推进，零卷积的权重逐渐从零开始学习，控制分支的信息才逐步、平稳地被注入进主干网络，使模型在保留原有生成质量的同时，学会让最终生成结果精确地遵循额外条件图的结构信息。

</details>

**11. Stable Diffusion 3 / FLUX 等新一代文生图模型相比早期 SD 有哪些架构改进？**

<details>
<summary>💡 查看答案</summary>

相比 Stable Diffusion 1.x/2.x 等早期版本，新一代模型在多个层面进行了系统性改进：

1. **去噪骨干网络的架构升级**：早期 SD 使用基于卷积网络的 U-Net 作为去噪骨干；新一代模型（如 SD3 的 MM-DiT，Multimodal Diffusion Transformer）改用基于 Transformer 的架构，同时将图像的（潜在空间）Patch Token 和文本 Token 输入同一个 Transformer 中进行联合处理，图像和文本各自拥有独立的一套权重参数但通过共享的 Attention 层交互，这种设计既保留了对两种模态分别建模的灵活性，又实现了更充分的图文信息融合，同时也带来了比 U-Net 更好的可扩展性（Scaling 特性）；
2. **训练目标的改进**：早期扩散模型普遍采用 DDPM 提出的噪声预测目标，其对应的加噪-去噪轨迹在概率空间中是弯曲的路径；新一代模型（如 SD3、FLUX）普遍采用**整流流**（Rectified Flow / Flow Matching）等训练目标，其核心思想是让模型学习一条从噪声到真实数据尽可能接近**直线**的传输路径，路径越直，意味着用更少的离散采样步数去近似这条路径时累积的误差越小，因此可以用远少于传统方法的采样步数（甚至个位数步数）就获得高质量的生成结果；
3. **文本编码器的增强**：早期 SD 主要依赖单一的 CLIP 文本编码器提取文本条件特征，CLIP 编码器本身是为图文对比学习设计的，对长文本、复杂逻辑关系的理解能力有限；新一代模型往往同时使用多个文本编码器组合（如同时使用 CLIP 和 T5-XXL），T5 这类专门的语言模型在理解复杂、包含多重限定和逻辑关系的长提示词方面能力更强，从而提升了模型对复杂提示词的响应准确度。

</details>

**12. 什么是一致性模型（Consistency Model）？如何加速扩散模型的采样速度？**

<details>
<summary>💡 查看答案</summary>

传统扩散模型的生成过程需要从纯噪声开始，沿着预先设定的加噪轨迹反向迭代去噪，每一步只能去除一小部分噪声，通常需要数十到上百步迭代才能得到高质量的最终图像，这使得推理速度成为扩散模型实际应用中的一大瓶颈。

一致性模型的核心思想是：直接训练一个函数 $f$，使得对于扩散轨迹上**任意**一个时间步（即任意噪声程度）的中间状态，将其输入函数 $f$ 后，输出结果都应该"一致地"映射回同一个终点——也就是原始的、无噪声的清晰数据。换句话说，模型学习的不是"去除一小步噪声"这种局部映射，而是直接学习"无论当前处于轨迹上哪个噪声程度，都能一步跳回干净数据"这种全局映射关系（自洽性约束：轨迹上任意两点通过函数 $f$ 映射后的结果应保持一致）。

训练完成后，生成新样本时不再需要沿着轨迹逐步、多次迭代地去噪，而是可以直接将一个随机噪声输入训练好的一致性函数，**一步**（或额外增加 1-4 步做小幅质量修正）就能得到高质量的生成结果，将传统扩散模型所需的采样步数从几十甚至上百步大幅压缩，是当前扩散模型推理加速最重要的技术方向之一，尤其适合对生成速度要求较高的实时或交互式应用场景。

</details>

**13. 图像编辑（Inpainting/Outpainting）在扩散模型中如何实现？**

<details>
<summary>💡 查看答案</summary>

**Inpainting（图像修复/局部重绘）**：给定一张原始图像和一个指定需要重新生成区域的遮罩（Mask），在扩散模型的每一步反向去噪过程中，对于遮罩之外（需要保留）的区域，直接用"原始图像对应区域按当前时间步加噪之后"的结果强制替换掉模型本身生成的内容；对于遮罩内部（需要重新生成）的区域，则让其按照扩散模型正常的去噪流程自由生成。通过在每一步都执行这种"替换"操作，最终生成结果就能实现"遮罩外严格保留原图内容、遮罩内根据条件（文本提示或留白）自由生成新内容"的效果，同时由于遮罩边界附近的区域在扩散过程中会自然地互相影响（Attention 和卷积的感受野会跨越遮罩边界），生成内容与保留区域之间通常能形成较为自然的过渡，而不会出现生硬的拼接痕迹。

**Outpainting（图像扩展/延展）**：思路与 Inpainting 类似，但应用场景是"向外扩展画布"而非"修改内部区域"——将原始图像放置在一个更大尺寸的空白画布中央（或任意需要扩展的方向），原图覆盖的区域视为需要"保留"的部分，画布中原图之外的空白区域视为需要"生成"的部分，用与 Inpainting 完全相同的机制（每步去噪时替换保留区域、自由生成待补全区域），让模型根据原图的边缘内容和光照、风格线索，向外自然延伸生成新的画面内容，实现扩大原图视野范围的效果。

</details>

**14. 什么是自回归图像生成（如 VAR、LlamaGen）？与扩散模型相比优劣如何？**

<details>
<summary>💡 查看答案</summary>

自回归图像生成延续了语言模型"逐个 Token 预测下一个 Token"的建模思路，应用到图像生成上：首先使用类似 VQ-VAE 的向量量化自编码器，将图像压缩编码为一个离散的、类似词表的视觉 Token 序列（每个 Token 对应一个来自有限"视觉词表"的编号），随后训练一个类似 GPT 的自回归 Transformer，以某种预定顺序（如逐行光栅顺序）逐个预测这些离散视觉 Token，生成时同样按照该顺序逐个采样出 Token 序列，最后再用解码器将 Token 序列还原为像素图像。

其中 VAR（Visual Autoregressive Modeling）等较新的工作对传统的逐 Patch 顺序生成方式做了改进，采用"由粗到细的多尺度自回归"：先生成一个很低分辨率（如 1×1 或 2×2）的粗略视觉 Token 布局，再逐步预测更高分辨率尺度下的 Token（每一步都以上一个更粗糙尺度的结果为条件），这种由粗到细的生成顺序更符合人类感知图像"先看整体轮廓、再看细节"的直觉，相比传统逐 Patch 顺序显著提升了生成速度和质量。

**相比扩散模型的优劣**：自回归方式的优势在于可以**直接复用**语言模型领域已经非常成熟的训练和推理基础设施（如 KV Cache 加速自回归解码、成熟的并行训练策略），并且更容易将图像生成能力和文本生成能力统一到同一个自回归框架下（即前面提到的"统一理解+生成"模型思路）；劣势在于，将连续的图像信号强行离散化为有限的视觉词表本身会带来一定的量化损失，且逐 Token 顺序生成（即便是多尺度由粗到细）在生成质量、细节丰富度和多样性上，目前多数工作与最先进的扩散模型相比仍存在一定差距，这也是当前图像生成领域扩散模型仍占据主导地位的原因。

</details>

**15. 统一的"图像理解+生成"模型（如 Chameleon、Emu、Janus）是如何设计的？**

<details>
<summary>💡 查看答案</summary>

这类模型的核心设计思路是打破"理解模型"和"生成模型"长期以来分离发展的局面，让**同一个模型**既能完成"看图说话"（图像理解，输出文本），也能完成"看文生图"（图像生成，输出像素），甚至支持图文交错混合生成（一段内容中文字和图片交替出现）。具体实现上，通常将图像统一编码为离散或连续的 Token（与文生图的自回归路线类似，常借助 VQ 类方法将图像量化为离散 Token），使其可以和文本 Token 一起，纳入**同一个**自回归 Transformer 中联合建模——模型在训练时既要学习"根据图像 Token 预测文本 Token"（理解任务），也要学习"根据文本 Token 预测图像 Token"（生成任务），两种能力共享同一套模型参数。

值得注意的是，部分较新的工作（如 Janus 系列）发现，"理解"和"生成"这两个任务对视觉特征的要求其实存在冲突：理解任务更需要高层语义抽象的特征（类似 CLIP 编码器提取的特征，便于与语言对齐），而生成任务更需要保留丰富像素细节的特征（便于精确重建图像）。因此 Janus 等模型选择**解耦视觉编码器**：使用一个语义特征强的编码器（如 SigLIP）专门服务于理解任务，另用一个像素重建能力强的编码器（如 VQ 类的 Tokenizer）专门服务于生成任务，两条独立的视觉处理路径最终都接入同一个统一的自回归 Transformer 主干，这种"编码器解耦、生成骨干统一"的设计，被证明能比强行共用同一套视觉特征取得更好的综合表现。

</details>

**16. Sora 等视频生成模型的核心技术思路是什么？**

<details>
<summary>💡 查看答案</summary>

以 Sora 为代表的先进文生视频模型，核心技术思路建立在"将扩散模型与 Transformer 结合，并把视频统一表示为时空 Patch 序列"这一框架之上：

1. **视觉Patch的时空扩展**：不同于图像扩散模型只处理二维空间 Patch，视频生成模型将视频在空间和时间两个维度上同时切分为一系列"时空 Patch"（Spacetime Patches），每个 Patch 既包含空间局部信息也包含时间局部信息，从而将视频这种四维数据（宽、高、时间、通道）转换为可以直接输入 Transformer 的一维 Token 序列。
2. **在压缩的潜在空间中操作**：与 Latent Diffusion 的思路类似，视频数据同样先通过一个视频压缩网络（时空自编码器）映射到维度更低的潜在空间，再在该潜在空间中进行时空 Patch 化和扩散过程，从而大幅降低直接在原始像素空间上处理高维视频数据的计算成本。
3. **统一处理可变时长/分辨率/宽高比**：由于时空 Patch 化的方式天然支持可变数量的 Token，这类模型可以在同一套架构下训练和生成不同时长、不同分辨率、不同宽高比的视频，而不需要像早期视频生成模型那样被固定的输入尺寸束缚。
4. **DiT 作为去噪骨干**：使用基于 Transformer 的扩散模型（DiT）架构作为去噪网络的主干，天然具备良好的可扩展性（Scaling），使得视频生成质量可以随着模型规模和训练算力的增加而持续提升，这与图像生成领域从 U-Net 转向 DiT 的趋势是一致的。

这套"时空 Patch + 潜在空间扩散 + DiT"的组合，被认为是当前实现高质量、长时长、高分辨率视频生成的关键技术路线，也是"世界模型"研究中用视频生成模拟物理世界动态的重要技术基础之一。

</details>
