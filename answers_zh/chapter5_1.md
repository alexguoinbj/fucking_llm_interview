# 5.1 RL 基础概念与框架 — 题目与答案
> [⬅ 返回目录](../README_ZH.md) · 第 5 章：强化学习与后训练对齐（RLHF / DPO） · 共 22 题

**1. 强化学习的基本概念解释一下？**

<details>
<summary>💡 查看答案</summary>

强化学习（Reinforcement Learning, RL）是机器学习的一个子领域，旨在通过**智能体（Agent）与环境（Environment）的持续交互**，学习一种能够最大化累积奖励的最优策略。其核心在于"试错"与"反馈"机制：智能体不断尝试不同的行动，环境给出奖励信号，智能体据此调整行为。

**核心要素**：
- **状态（State, S）**：描述当前环境的完整信息，如棋盘局面或对话上下文；
- **动作（Action, A）**：智能体可以执行的操作，在 LLM 场景中对应每个生成的 token；
- **奖励（Reward, R）**：环境对智能体行动给出的即时反馈信号，可正可负；
- **策略（Policy, $\pi$）**：从状态到动作的映射函数，即智能体的"决策规则"；
- **价值函数（Value Function, V/Q）**：评估某状态（或状态-动作对）的长期期望回报。

**优化目标**：最大化累积折扣奖励 $G_t = \sum_{k=0}^{\infty} \gamma^k r_{t+k}$，其中折扣因子 $\gamma \in [0,1]$ 控制对未来奖励的重视程度。

**与监督学习的核心区别**：监督学习有明确的"正确答案"作为标签；强化学习没有标准答案，只有稀疏的奖励信号，且当前行动会影响未来的状态分布（时序相关性）。这使得 RL 在无法事先穷举所有优质行为的场景（如对话、推理）中具有独特优势。

**在 LLM 中的对应关系**：LLM 的 token 生成过程天然符合 RL 框架——每个时间步选择一个 token（动作），生成完整回复后获得人类偏好奖励（奖励），通过 PPO/GRPO 等算法更新模型参数（策略优化）。

</details>

**2. 强化学习包含哪些关键要素？**

<details>
<summary>💡 查看答案</summary>

强化学习问题通常被建模为一个马尔可夫决策过程（MDP），包含以下关键要素：
1. **状态（State, S）**：智能体所处的环境状态。
2. **动作（Action, A）**：智能体在特定状态下可以执行的操作。
3. **状态转移（Transition Dynamics, P）**：从当前状态 $s$ 执行动作 $a$ 后，转移到下一个状态 $s'$ 的概率。
4. **奖励（Reward, R）**：智能体在每个时刻获得的即时回报。
5. **折扣因子（Discount Factor, $\gamma$）**：用于平衡当前奖励与未来奖励的重要性，取值范围通常为 $(0, 1]$。

</details>

**3. 强化学习的两个关键特征？**

<details>
<summary>💡 查看答案</summary>

首先，它依赖于持续的试错过程来发现最优行为；其次，它必须处理延迟回报的问题。这使得 RL 与监督学习在评价模型的方式上有显著不同：
- **监督学习**：模型根据已知的正确答案获得即时反馈，学习过程直接针对减少预测误差。
- **强化学习**：智能体通过与环境的互动来评估其行为，只有通过累积奖励的评估，才能确定策略的有效性。

</details>

**4. 马尔可夫过程有哪些性质？**

<details>
<summary>💡 查看答案</summary>

马尔可夫性质（Markov Property）是强化学习理论体系的核心假设，也称为**"无记忆性"或"一步依赖性"**。

**核心定义**：给定当前状态 $S_t$，未来状态 $S_{t+1}$ 的条件概率与历史状态序列 $S_0, S_1, ..., S_{t-1}$ 无关，即：
\[P(S_{t+1} | S_t, A_t) = P(S_{t+1} | S_0, S_1, ..., S_t, A_0, ..., A_t)\]
当前状态已经充分概括了所有历史信息，完全决定了系统的未来演化。

**几个重要性质**：
- **状态充分性**：当前状态 $S_t$ 是做出最优决策所需的充分统计量，不需要回顾历史；
- **时间齐次性（Homogeneous MDP 的额外假设）**：状态转移概率 $P(s'|s,a)$ 不随时间变化；
- **贝尔曼方程的基础**：满足马尔可夫性的过程构成马尔可夫决策过程（MDP），可用贝尔曼方程将长期价值分解为递推关系：$V^*(s) = \max_a [R(s,a) + \gamma \sum_{s'} P(s'|s,a) V^*(s')]$

**在 LLM 中的应用与局限**：在 LLM 的 token 生成过程中，将"当前已生成的完整序列（KV Cache 记录的所有上下文）"作为状态，可以满足马尔可夫性。然而实践中，受窗口长度限制，LLM 可能无法看到全部历史，这在一定程度上违背了严格意义上的马尔可夫假设。

</details>

**5. LLM 中的 RL 怎么理解？**

<details>
<summary>💡 查看答案</summary>

将强化学习与大语言模型的结合理解如下：

- **状态（State, S）**：状态是输入的 prompt（提示或问题），即用户提供的文本输入。状态是智能体（LLM）需要处理的信息，决定了其下一步的决策。
- **动作（Action, A）**：动作是 LLM 的输出 response（响应），即模型生成的下一个 token（或一段文本）。动作是模型在当前状态下做出的决策，决定了生成内容的质量和方向。
- **奖励（Reward, R）**：奖励是根据 prompt + response 的组合，由奖励模型（Reward Model, RM）给出的评分。奖励信号用于衡量生成内容的质量，指导模型调整策略以生成更好的内容。
- **整体目标**：给定一个 prompt，通过调整策略（policy）来生成符合人类偏好的 response。

</details>

**6. 大模型里应用强化学习时，状态，动作空间，动作都是什么**

<details>
<summary>💡 查看答案</summary>

在将 LLM 训练建模为强化学习问题时（以 RLHF 为例），各要素的对应关系如下：

- **状态（State）**：当前的"上下文"，即到目前为止已经生成的所有 token 序列，包括 prompt 和已生成的部分回复。即在生成第 t 个 token 时，状态 $s_t$ = (prompt, $y_1$, $y_2$, ..., $y_{t-1}$)——状态随着每生成一个新 token 而更新（新 token 被追加到上下文中）。

- **动作空间（Action Space）**：词表（vocabulary）中所有可能的 token，即模型在每一步可以选择输出的所有 token 的集合，动作空间的大小等于词表大小（通常几万到十几万）。

- **动作（Action）**：在状态 $s_t$ 下，策略模型（LLM）实际采样/选择输出的某一个具体 token，即 $a_t$ = $y_t$。

- **策略（Policy）**：即 LLM 本身，$\pi_{\theta}$($a_t$ | $s_t$) 表示在给定上下文（状态）下，模型对词表中每个 token 的输出概率分布。

- **轨迹（Trajectory/Episode）**：从给定 prompt 开始，逐 token 生成直到产生 EOS（或达到最大长度）的完整生成过程，构成一个"episode"，对应一个完整的回复。

- **奖励（Reward）**：通常是稀疏的——只在生成结束（整个回复完成）时，由奖励模型对整个 (prompt, response) 给出一个标量奖励；中间每一步的"即时奖励"通常为 0（在加入 KL 惩罚的实现中，每一步也会有一个基于 KL 的小额惩罚信号）。

**总结**：状态是"当前已生成的上下文"，动作空间是"词表"，动作是"当前步选择输出的 token"，整个生成过程构成一条轨迹，奖励通常在轨迹末尾才给出，是一个典型的"序列决策、稀疏奖励"问题。

</details>

**7. 经典 RL 算法的分类说一下？**

<details>
<summary>💡 查看答案</summary>

强化学习算法可以根据不同的标准进行分类：

1. **基于模型的（Model-Based）和无模型的（Model-Free）**：
    - 基于模型的：依赖于对环境的模型来进行决策，如 AlphaGo/AlphaZero、MuZero。
    - 无模型的：不依赖环境模型，直接从与环境的交互中学习。
2. **基于价值的（Value-Based）和基于策略的（Policy-Based）**：
    - 基于价值的：通过学习状态的价值函数或动作价值函数来进行决策，如 Q-Learning、DQN。
    - 基于策略的：直接学习一个策略函数，如 Policy Gradient、TRPO/PPO。
3. **在线策略（On-Policy）和离线策略（Off-Policy）**：
    - 在线策略：使用当前策略生成的数据来更新策略，如 SARSA。
    - 离线策略：可以使用其他策略生成的数据来更新当前策略，如 Q-Learning、DQN。

</details>

**8. 通用 RL 和大模型 RL 的关键区别？**

<details>
<summary>💡 查看答案</summary>

通用强化学习（游戏、机器人控制等）和大模型 RL（LLM 后训练）在核心组件和挑战上存在多个关键区别：

**1. 动作空间维度**
- **通用 RL**：动作空间通常小而有限（如围棋的 361 个落子位置，或机器人控制的连续关节角度）；
- **大模型 RL**：动作空间是词汇表大小（3-10 万个 token），且每个时间步都在这个超高维空间中选择一个动作，基于价值的方法（Q-Learning）几乎不可行。

**2. 状态转移的确定性**
- **通用 RL**：状态转移通常由真实物理世界或确定性游戏规则决定；
- **大模型 RL**：状态转移完全确定——给定已生成的 token 序列，下一状态就是当前序列 + 新生成的 token，不存在随机性的状态转移（随机性只在 token 采样时引入）。

**3. Episode 的结构**
- **通用 RL**：一个 episode 可以包含数千到数百万个时间步（如训练游戏 AI）；
- **大模型 RL**：一个 episode 通常只有几十到几千个 token，整体较短，但每个 token 的模型前向计算代价极高。

**4. 奖励信号的稀疏性**
- **通用 RL**：根据任务不同，奖励可以是稠密的（每步都有）或稀疏的（只在终止时）；
- **大模型 RL**：奖励几乎总是在**整条 response 生成完成后才给出**（序列级稀疏奖励），这是 RLHF 信用分配难题的根本来源。

**5. 策略参数规模**

- **通用 RL**：策略网络通常较小（数百万参数）；
- **大模型 RL**：策略模型本身就是 LLM（数十亿到数千亿参数），单次前向计算就消耗大量算力，训练效率要求极高。

</details>

**9. 强化学习中的 on-policy 和 off-policy 有什么区别？**

<details>
<summary>💡 查看答案</summary>

On-policy 和 Off-policy 是强化学习中描述**用于更新策略的数据来源**的核心概念，两者的根本区别在于"生成数据的策略"与"被优化的策略"是否一致。

**定义对比**：
- **On-policy（在线策略）**：用于计算梯度和更新参数的样本数据，**必须由当前正在被优化的策略 $\pi_\theta$ 生成**。每次策略更新后，旧数据就"过期"了，需要重新采集；
- **Off-policy（离线策略）**：可以使用**任意其他策略（行为策略 $\mu$，如历史版本、人工标注）**生成的数据来更新目标策略 $\pi_\theta$，两者可以不同。

**核心技术区别**：

Off-policy 方法通常需要**重要性采样（Importance Sampling）**来修正数据分布差异：
\[\mathbb{E}_{a \sim \mu}[f(a)] = \mathbb{E}_{a \sim \pi}\left[\frac{\mu(a|s)}{\pi(a|s)} f(a)\right]\]
引入重要性权重 $w = \pi(a|s)/\mu(a|s)$ 来"重新加权"旧策略的数据，使其等价于用新策略采集的数据。PPO 正是利用此原理实现"近端 on-policy"（在有限范围内复用旧数据）。

**在 LLM 场景中的对应**：
- **PPO/GRPO**：本质上是 on-policy 方法，每轮 rollout 使用当前策略生成回复，更新后数据丢弃，重新采样；
- **DPO**：使用预先收集的人类偏好对（生成自 SFT 模型或其他策略），是典型的 off-policy 方法；
- **Iterative DPO**：每轮用最新策略重新采样数据再做 DPO，是 on-policy 和 off-policy 的折中。

**核心权衡**：On-policy 梯度估计无偏但样本效率低；Off-policy 样本效率高但面临分布偏移风险。PPO 通过 clip 机制实现两者的平衡，这也是 PPO 被广泛采用的根本原因。


![On-policy 与 Off-policy 数据流对比](https://img.pricenode.uk/llm_interview_questions/zhongw/chapter5/fig_on_off_policy.png)

</details>

**10. 为什么要区分 on-policy 和 off-policy？**

<details>
<summary>💡 查看答案</summary>

1. **策略分布一致性**：如果数据来自与目标策略不同的分布，则需要额外的技术（如重要性采样）来确保学习的正确性。
2. **数据效率**：On-policy 方法通常“采样-训练-丢弃”，数据无法重复利用；而 off-policy 方法可以通过经验回放等方式重复利用数据。
3. **安全性与可控性**：off-policy 方法可以通过保守的行为策略收集数据，同时学习更激进的目标策略。

</details>

**11. 说一下 on-policy 和 off-policy 的代表性算法？**

<details>
<summary>💡 查看答案</summary>

**On-Policy（在线策略）代表算法**：
- **SARSA**：经典 on-policy TD 算法，更新时使用当前策略实际执行的动作；
- **A2C/A3C**：Actor-Critic 方法，基于当前策略采集的数据进行更新；
- **PPO**：通过重要性采样允许多次小批量更新，用 clip 机制控制策略变化幅度，是 LLM RL 的核心算法；
- **GRPO**：PPO 的改进版，去除 Critic，使用组内归一化估计优势。

**Off-Policy（离线策略）代表算法**：
- **Q-Learning**：最经典的 off-policy 算法，更新时使用 $\max_{a'} Q(s',a')$（贪心策略），与实际行为策略无关；
- **DQN（Deep Q-Network）**：将 Q-Learning 与深度网络结合，引入经验回放池，典型的 off-policy 方法；
- **SAC（Soft Actor-Critic）**：最大熵强化学习框架，利用经验回放，高效处理连续动作空间；
- **DPO**：在 LLM 对齐中是典型的 off-policy 方法，使用预先收集的偏好数据训练，不做在线采样。

在 LLM 后训练场景中，on-policy 的 PPO/GRPO 与 off-policy 的 DPO 是两大主流对齐算法——前者训练更稳健但成本高，后者简单高效但依赖数据质量。

</details>

**12. 说一下 on-policy 和 off-policy 的优缺点？**

<details>
<summary>💡 查看答案</summary>

**On-Policy 优缺点**：

**优点**：
- **理论保证强**：训练数据与当前策略分布完全一致，无分布偏移问题，梯度估计无偏；
- **训练稳定**：避免了 off-policy 中数据与当前策略分布差异带来的不稳定性；
- **探索有效**：每轮都基于最新策略采集新数据，能持续探索当前策略附近的动作空间。

**缺点**：
- **样本效率低**：每批数据只能用于一次（或有限次）更新，更新后数据即"过期"，无法复用历史经验；
- **计算成本高**：在 LLM 场景中，每轮更新都需要进行昂贵的在线 rollout（自回归生成），是训练瓶颈；
- **难以并行化**：数据采集和参数更新存在强依赖，难以完全异步化。

**Off-Policy 优缺点**：

**优点**：
- **样本效率高**：可以复用历史经验（经验回放），同样的数据反复利用，大幅降低所需交互次数；
- **训练成本低**：DPO 等方法无需在线采样，类似监督学习，实现和调试更简单；
- **支持离线数据**：可以直接利用历史收集的数据集（如人类标注的偏好对），无需实时与环境交互。

**缺点**：
- **分布偏移风险**：训练数据分布与当前策略分布不一致，可能导致价值估计偏差，甚至训练发散；
- **过拟合风险**：DPO 等方法容易过拟合到固定的偏好数据集，泛化能力受限；
- **探索能力弱**：无法通过在线探索发现数据集之外的更优策略。

</details>

**13. 强化学习中的 online 和 offline 有什么区别？**

<details>
<summary>💡 查看答案</summary>

Online/Offline 与 On-policy/Off-policy 是两组不同维度的分类，描述 RL 训练数据来源和更新方式的不同方面。

**Online（在线学习）**：

智能体在训练过程中**实时与环境交互**，边收集新数据边更新策略。
- **特点**：数据是动态生成的，可以根据当前策略的探索需求自适应地收集；
- **优点**：能持续获得当前策略分布下的最新数据，适应策略的变化；
- **缺点**：需要实时环境交互，在 LLM 场景中意味着需要在线 rollout 采样，计算成本高；
- **典型算法**：PPO、GRPO、SAC、DQN（含经验回放）。

**Offline（离线学习）**：

智能体使用**预先收集的静态数据集**进行学习，训练过程中不与环境交互。
- **特点**：数据集固定不变，策略只能从已有数据中学习；
- **优点**：无需实时环境，可充分利用历史数据，训练成本低；
- **挑战**：分布外（OOD）问题严重——策略可能学到超出数据覆盖范围的错误动作；
- **典型算法**：DPO（使用预先收集的偏好对数据集），CQL，IQL。

**与 On/Off-policy 的关键区别**：
- On/Off-policy 描述的是**用于更新的数据是否来自当前策略**（数据生成策略 vs 优化策略是否一致）；
- Online/Offline 描述的是**训练期间是否与环境实时交互**（数据是动态收集还是静态使用）。
- 注意：Online 算法不一定是 On-policy（如 DQN 是 Online + Off-policy），Offline 算法通常是 Off-policy，但反之未必成立。

在 LLM 对齐中：PPO/GRPO 是 Online+On-policy；DPO 是 Offline+Off-policy；Iterative DPO 则是 Online+Off-policy 的折中方案。

</details>

**14. on/off-policy 和 online/offline 的区别是什么？**

<details>
<summary>💡 查看答案</summary>

1. **不同维度**：On/off-policy 解决的问题是“采样策略”与“目标策略”的一致程度；Online/offline 解决的问题是“是否可以持续交互收集新数据”。
2. **常见组合**：离线强化学习基本一定是 off-policy，但在线强化学习可以既有 on-policy，也可以有 off-policy。

</details>

**15. RL 中 on/off line 以及 on/off policy 的区别和联系**

<details>
<summary>💡 查看答案</summary>

- **Online + On-policy**：实时交互并仅用当前策略的数据更新（如 PPO）。
- **Online + Off-policy**：实时交互但用历史数据更新（如 DQN 使用经验回放）。
- **Offline + Off-policy**：最常见组合，使用静态数据集更新策略（如 BCQ、CQL）。
- **Offline + On-policy**：理论上可能，但实际中几乎不存在。

</details>

**16. 优势函数与值函数、动作值函数的关系是什么？**

<details>
<summary>💡 查看答案</summary>

优势函数（A）与值函数（V）和动作值函数（Q）之间的关系是：优势函数是 Q 函数和 V 函数的差值。
- **值函数（V）**：衡量一个状态的价值，反映了智能体在该状态下根据当前策略所能期望获得的总回报。
- **动作值函数（Q）**：衡量在某个状态下采取某个动作后，智能体所能期望获得的总回报。
- **优势函数（A）**：用于评估某个动作相对于平均策略的回报增益，是一个动作对比的度量。

</details>

**17. 估计值函数的三种常见方法有哪些？**

<details>
<summary>💡 查看答案</summary>

在强化学习中，估计值函数是关键步骤，常见的三种方法包括：
1. **蒙特卡洛方法（MC）**：通过完整的轨迹采样来估计值函数。
2. **时间差分方法（TD）**：利用部分轨迹信息进行估计。
3. **广义优势估计（GAE）**：结合了蒙特卡洛和时间差分方法的优点，通过折中偏差和方差来提高估计的稳定性和效率。

</details>

**18. 从偏差角度总结下估计值函数的三种方法？**

<details>
<summary>💡 查看答案</summary>

1. **MC 方法**：高方差，由于依赖完整的 Episode 回报，更新值可能受到随机因素的较大影响；无偏性，直接使用实际累积回报进行更新。
2. **TD 方法**：低方差，利用每一步的即时奖励进行更新；高偏差，依赖当前估计值进行更新，容易引入偏差。
3. **GAE 方法**：折中性，通过调整参数 $\lambda$，可以在偏差和方差之间灵活权衡。当 $\lambda$ 接近 0 时，更接近 TD 方法；当 $\lambda$ 接近 1 时，更接近 MC 方法。

</details>

**19. 蒙特卡洛方法的优缺点是什么？**

<details>
<summary>💡 查看答案</summary>

蒙特卡洛（MC）方法通过**完整轨迹的实际回报**来估计价值函数，不使用自举（bootstrapping）。

**优点**：
- **无偏估计**：直接使用实际回报 $G_t = r_t + \gamma r_{t+1} + \gamma^2 r_{t+2} + ...$，不依赖其他估计量，在期望意义上是无偏的，不引入系统性误差；
- **不需要环境模型**：不依赖转移概率，是完全的 model-free 方法；
- **对非马尔可夫性质更鲁棒**：使用实际回报而非递推估计，对马尔可夫假设的违反不敏感；
- **适合 episodic 任务**：在有明确开始和结束的任务中（如一条 LLM 回复）实现简单。

**缺点**：
- **方差大**：完整轨迹中每一步的随机性都会累积到最终回报，导致估计值方差很高，训练不稳定；
- **必须等到 episode 结束才能更新**：无法在线更新，不适合连续性任务或 episode 很长的场景；
- **对长轨迹效率低**：在 LLM 生成场景中，若回复很长（如 CoT 推理数千 token），等待完整生成后才能更新，实时性差；
- **信用分配困难**：在稀疏奖励的长序列中，难以从最终回报中辨别哪些中间步骤真正做出了贡献。

**在 LLM RL 中的体现**：REINFORCE 算法本质上是 MC 方法；GRPO 用"组内归一化"降低 MC 方差；PPO 则引入 Critic（TD 估计）进一步替换 MC 回报，在偏差与方差之间取得平衡。

</details>

**20. 时间差分方法的优缺点是什么？**

<details>
<summary>💡 查看答案</summary>

时间差分（Temporal Difference, TD）方法综合了蒙特卡洛和动态规划的思想，通过**自举（Bootstrapping）**在每一步就进行价值更新：$V(S_t) \leftarrow V(S_t) + \alpha[r_{t+1} + \gamma V(S_{t+1}) - V(S_t)]$。

**优点**：
- **方差小**：每步只用一个即时奖励 $r_{t+1}$ 加上下一步的价值估计，随机性来源少，方差远低于 MC；
- **支持在线/增量更新**：无需等到 episode 结束，每一步即可更新，适合连续任务和长序列任务；
- **数据效率更高**：每个时间步都利用了当前经验，不浪费中间步骤；
- **在实践中通常收敛更快**：尽管有偏，但低方差使得实际学习速度通常优于 MC。

**缺点**：
- **有偏估计（Biased）**：TD 使用当前的价值估计 $V(S_{t+1})$ 进行自举，而这个估计本身不准确，引入了系统性偏差；随着价值函数收敛，偏差逐渐减小，但无法完全消除；
- **对马尔可夫假设敏感**：TD 自举的有效性依赖当前状态充分概括了历史信息，若该假设违反，价值估计可能出现系统性错误；
- **函数逼近时的不稳定性**：当与非线性函数近似（如神经网络）结合时，TD 学习可能出现"致命三角"（deadly triad）问题，导致发散。

**在 LLM RL 中的体现**：PPO 的 Critic 本质上是 TD 学习——Critic 利用 GAE（TD($\lambda$) 的变体）在每个 token 位置估计优势函数，兼顾了低方差（自举）和低偏差（多步展开）。

</details>

**21. 广义优势估计（GAE）是什么？**

<details>
<summary>💡 查看答案</summary>

广义优势估计（Generalized Advantage Estimation, GAE）由 Schulman 等人提出，是一种结合蒙特卡洛和时间差分思想的**优势函数估计方法**，核心目的是在偏差和方差之间取得平衡。

**核心思想**：

单步 TD 的优势估计（$\delta_t = r_t + \gamma V(S_{t+1}) - V(S_t)$）方差小但偏差大；MC 回报偏差小但方差大。GAE 通过引入超参数 $\lambda$ 对不同时间步的 TD 误差进行指数加权平均：
\[A_t^{GAE(\gamma,\lambda)} = \sum_{l=0}^{\infty} (\gamma\lambda)^l \delta_{t+l}\]
其中 $\delta_{t+l} = r_{t+l} + \gamma V(S_{t+l+1}) - V(S_{t+l})$ 是第 $t+l$ 步的 TD 误差。

**参数 $\lambda$ 的作用**：
- $\lambda = 0$：退化为单步 TD 误差，偏差最大但方差最小；
- $\lambda = 1$：退化为 MC 回报（减去基线），方差最大但偏差最小；
- $0 < \lambda < 1$（通常取 0.9-0.99）：在偏差和方差之间灵活权衡，实践中表现最好。

**在 PPO 中的应用**：PPO 使用 GAE 估计每个 token 位置的优势值 $A_t$，再用 $A_t$ 加权策略梯度更新 Actor，同时训练 Critic 拟合真实价值函数 $V(s)$。GAE 是 PPO 相比纯 REINFORCE 能够更稳定训练的关键技术之一。

</details>

**22. 广义优势估计（GAE）的优缺点是什么？**

<details>
<summary>💡 查看答案</summary>

**GAE 的优点**：
- **偏差-方差可控**：通过 $\lambda$ 参数在 TD（低方差高偏差）和 MC（高方差低偏差）之间连续插值，可以根据任务特性灵活调整，是当前 RL 训练中最实用的优势估计方法；
- **减少对 Critic 精度的依赖**：$\lambda > 0$ 时，GAE 引入了真实回报的成分，减弱了 Critic 估计偏差对优势估计的影响；
- **信用分配更合理**：相比单步 TD，GAE 考虑了多步未来奖励，能更准确地将末尾奖励归因到早期关键动作，对稀疏奖励场景尤为重要；
- **与 PPO 自然兼容**：GAE 估计的优势函数方差适中，与 PPO 的 clip 机制配合使用训练非常稳定，是工业界大规模 RL 训练的标配。

**GAE 的缺点**：
- **需要 Critic 模型**：GAE 依赖价值函数 $V(s)$ 的估计，必须同时维护和训练 Critic，增加了显存和计算开销——这正是 GRPO 去除 Critic、改用组内归一化来规避的缺点；
- **超参数敏感**：$\lambda$ 参数需要仔细调整，不同任务的最优值差异较大；
- **计算成本更高**：需要对每个 token 位置计算加权累积，且需要等到序列结束后才能从后向前计算完整的 GAE 估计；
- **GRPO 等简化方法的挑战**：GRPO 通过组内相对奖励归一化完全规避了 GAE 和 Critic，虽然精度可能略低，但大幅降低了工程复杂度，在推理型任务上往往取得相当甚至更好的效果。

</details>
